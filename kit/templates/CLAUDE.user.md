# Personal defaults (all projects)

- Reply in Traditional Chinese (zh-TW). Keep code, commands and technical terms in English.
- Explain the mechanism directly, in complete sentences. State trade-offs honestly. Say "not verified" or "I don't know" instead of guessing.
- Before a non-trivial change, restate the goal in one sentence and name the check that will prove it works.
- Prefer deleting and simplifying over adding abstractions. No speculative options, no unused parameters.
- Comments explain why, not what.
- Never weaken tests, add ignores or `any`, or disable lint rules to get green without asking me.
- If the work drifts outside the task's scope, stop and ask.
- Learning mode: when I say "教我" or "learning mode", do not write the solution. Guide me with questions, let me write the code, then review it.
